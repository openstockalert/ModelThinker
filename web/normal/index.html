Ch. 5 · Distributions

Where does the bell curve come from?

Watch it emerge live — from something as dumb as a ball bouncing off pegs.

Below is a Galton board: a triangle of pegs with bins along the bottom. Every ball you drop makes n tiny coin flips as it falls — left or right at each row. Its final bin equals the number of "rights" it took. Drop a hundred balls and watch what shape the pile settles into.

🔵 blue = balls piling up in bins  ·  red curve = the normal N(n/2, √(n/4)) the CLT predicts. The pile should hug the curve after a few hundred drops.

Try n = 4. Only 4 coin flips per ball — so only 5 possible bins. The pile is clearly discrete but already vaguely bell-shaped. Push n up to 18. Now each ball is a tiny statistical process, and the pile smooths into a proper bell. That transition, from "wobbly" to "bell", is the CLT.

It works for anything, not just coins

The magic isn't the coin flip. Whenever you sum many small independent random things — whatever they individually look like — the total is approximately normal. Pick any source distribution below (even a skewed one) and average n draws together. Bell curve, every time.

The √n rule

The bell doesn't just appear — it also tightens. Doubling n only shrinks its width by √2. That's why quadrupling the sample size halves the standard error, not doubling.

Empirical std vs sample size · log-log

Slope on log-log should be −½ if the √n rule holds. Every step to the right = 4× the sample size = ½× the error.

The small-schools puzzle. A famous US education initiative funded splitting big schools into small ones because small schools kept showing up among the top test performers. But small schools also showed up among the bottom performers — for exactly the same statistical reason. σ/√n is bigger when n is small. Wider extremes on both sides. The signal wasn't school quality; it was sample size.
